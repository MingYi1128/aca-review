# 模擬考 0：隨堂練習卷（原題）

> 題目全部是 9/21、10/12、10/19 的隨堂練習原題，題號重新編排。老師說考試 70~80 分出自隨堂練習，這份要練到**不看講義、限時內寫完**。
> 建議時間：90 分鐘｜閉書｜可用計算機（若考試不能用就不要用）

---

**1.（5 分）** Give the definition of big O function. 〔§3-A Q1〕

**2.（10 分）** Show that $f(n)=4n^5-3n^4+12n^3-8n^2+4=O(n^5)$. 〔§3-A Q2〕

**3.（10 分）** Apply the insertion sort to the sequence of numbers: 5, 2, 4, 6, 1, and 3 step by step. 〔§3-B Q1〕

**4.（6 分）**
(a) What are the worst and best cases of insertion sort?
(b) Give a data sequence of the best (worst) case of insertion sort. 〔§3-B Q2、Q3〕

**5.（12 分）** Analyze the best, worst, and average case time complexities of the insertion sort. 〔§3-B Q4〕

**6.（9 分）** Apply the binary search algorithm to search for 0, 3, and 17 in the sorted array: 1, 3, 5, 7, 9, 10, 12, 16 step by step. 〔§3-C Q1〕

**7.（8 分）** Construct a binary search tree corresponding to the sorted array: 1, 3, 5, 7, 9, 10, 12, 16. Starting at the root, assign a unique number from 1 to n, where n = 8, to each node in the tree. Number the nodes sequentially, level by level, from top to bottom. Assign the number 1 to the root, and complete the numbering of all nodes at a given level before proceeding to the next level. 〔§3-C Q2〕

**8.（6 分）** Verify that the number of comparisons required to successfully search for the data element assigned the number $i$ in the corresponding binary search tree of Problem 7 is $\lfloor\lg i\rfloor+1$. 〔§3-C Q3〕

**9.（6 分）** Determine the worst-case scenarios for successful and unsuccessful binary searches on the sorted array: 1, 3, 5, 7, 9, 10, 12, 16. Then, verify that the maximum number of comparisons in the corresponding binary search tree is $\lfloor\lg n\rfloor+1$, where n = 8. 〔§3-C Q4〕

**10.（10 分）** Show that the total number of comparisons required for all successful binary searches in a sorted array of $n$ elements, namely $(\lfloor\lg1\rfloor+1)+(\lfloor\lg2\rfloor+1)+\dots+(\lfloor\lg n\rfloor+1)$, is at most $n\lg n+(1-\frac{1}{\ln2})n+\lg n+\frac1{\ln2}$. 〔§3-C Q5〕

**11.（8 分）** Show that the total number of comparisons required for all unsuccessful binary searches in a sorted array of $n$ elements is at most $(\lfloor\lg n\rfloor+1)(n+1)\le n\lg n+n+\lg n+1$. 〔§3-C Q6〕

**12.（10 分）** Show that the average-case time complexity of binary search is $O(\lg n)$. 〔§3-C Q7〕
